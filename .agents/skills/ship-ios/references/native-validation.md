# Native validation

Run app commands from `native/`: its scripts are in
[native/package.json](../../../../native/package.json), and its build settings
in [app.json](../../../../native/app.json) and
[app.config.js](../../../../native/app.config.js). The
[blanc-native checks](../../blanc-native/SKILL.md#checks) cover the type-check,
simulator runs, launch arguments, lock-screen, widget and run checks, and phone
builds.

`native/ios` is generated by `npx expo prebuild --platform ios` and is not
committed. Prebuild again with `--clean` after changing app.json,
app.config.js, a config plugin, the widget target's files or a native module's
files, and when switching between the test app and the released app
(`HYPER_APP=release`). Run `native/scripts/use-rn-core.sh Debug|Release` before
a build whose configuration differs from the last one.

## Native contracts

- Native modules live in `native/modules` (Keychain session, HealthKit, run
  recorder, barcode scanner, Live Activity, widget data, view frames), each
  with its Swift beside its TypeScript API.
- The widget extension (`native/targets/widgets`) is added on prebuild by
  [withHyperWidgets.js](../../../../native/plugins/withHyperWidgets.js).
  `WorkoutActivityAttributes` has one definition in
  `native/modules/hyper-activity/ios`, copied into the extension; ActivityKit
  matches the app's and the extension's copies by name and fields.
- The Keychain session and URL schemes follow the bundle ID iOS reports.
  Preserve auth during unrelated work; when auth changes are explicitly
  requested, validate the sign-in callback on a device before release.
- Physical-device checks remain necessary for the keyboard, camera and barcode
  scanner, haptics, background location, notifications, widgets and Live
  Activities affected by the change.

## App icon

The icon is the red italic P in three appearances: `icon.png`, `icon-dark.png`
and `icon-tinted.png` in `native/assets/images`, set in app.json (`icon` and
`ios.icon`). Replace them with opaque 1024 × 1024 PNGs, then prebuild with
`--clean`. The P's font (Fraunces Mark Medium Italic, OFL) is in
`native/assets/fonts`. iOS applies its own icon effects, so report on-device
appearance as unverified until observed.
